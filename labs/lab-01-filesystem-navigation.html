Mastering Linux File System Navigation

Linux-এ file system-এ চলাফেরা করতে পারাটা সবচেয়ে গোড়ার দক্ষতা। এই lab-এ তুমি একটা practice directory বানাবে, তার ভেতরে ঘুরবে, file খুঁজবে, আর file-এর ভেতরের লেখা খুঁজবে — pwd, cd, ls, find আর grep দিয়ে।

এই lab শেষে যা পারবে

  • pwd দিয়ে বুঝবে তুমি এখন কোথায় দাঁড়িয়ে আছো।
  • cd দিয়ে absolute আর relative — দুই রকম path ধরেই চলাচল করবে।
  • ls দিয়ে কোনো directory-র ভেতরে কী আছে দেখবে, hidden file সহ।
  • find দিয়ে নাম ধরে file খুঁজবে।
  • grep দিয়ে file-এর ভেতরের লেখা খুঁজবে।
দরকারি

একটা Linux terminal বা WSL, আর terminal-এ টাইপ করার সামান্য অভ্যাস। এই lab-এ কোনো sudo লাগবে না — সব কাজ তোমার নিজের home directory-র ভেতরে।

Lab Setup

প্রথমে practice করার জন্য একটা directory structure বানিয়ে নিই। নিচের command গুলো একসাথে terminal-এ চালাও:

bash — setup
# মূল directory গুলো বানাও
mkdir -p ~/code/lab/projects/website
mkdir -p ~/code/lab/documents/reports
mkdir -p ~/code/lab/documents/notes

# কিছু নমুনা file বানাও
echo "Hello World"   > ~/code/lab/projects/website/index.html
echo "Project Plan"  > ~/code/lab/documents/reports/plan.txt
echo "Meeting Notes" > ~/code/lab/documents/notes/meeting.txt
echo "Todo List"     > ~/code/lab/documents/notes/todo.txt

mkdir -p-এর -p মানে — মাঝের directory গুলো না থাকলে সেগুলোও বানিয়ে নাও। আর echo "..." > file মানে — লেখাটা screen-এ না দেখিয়ে file-এ লিখে দাও।

এখন যে structure টা তৈরি হলো, সেটা দেখতে এমন:

তৈরি হওয়া structure
~/code/lab/
├── projects/
│   └── website/
│       └── index.html      ← "Hello World"
└── documents/
    ├── reports/
    │   └── plan.txt        ← "Project Plan"
    └── notes/
        ├── meeting.txt     ← "Meeting Notes"
        └── todo.txt        ← "Todo List"

অনুশীলন

pwd — আমি এখন কোথায়?

লক্ষ্য: file system-এ নিজের বর্তমান অবস্থান জানা।

bash
$ pwd
output
/root
তোমার নিজের output আলাদা হতে পারে — যেমন /home/mostofa। এটাই তোমার home directory।

ব্যাখ্যা: pwd মানে Print Working Directory। Shell সবসময় কোনো না কোনো directory-তে "দাঁড়িয়ে" থাকে — সেটাই তোমার current working directory। কোনো command relative path দিলে সেটা এই জায়গা থেকেই হিসেব হয়।

cd — এক জায়গা থেকে আরেক জায়গায়

লক্ষ্য: absolute আর relative — দুই রকম path দিয়েই চলাচল করা।

bash
$ cd ~/code/lab

~ চিহ্নটা তোমার home directory-র শর্টকাট। তাই ~/code/lab মানে /home/তোমার-নাম/code/lab।

এবার ভেতরে ঘুরে দেখো:

bash
# projects-এ ঢোকো
$ cd projects
$ pwd                             # কোথায় আছি মিলিয়ে নাও

# এক ধাপ উপরে ফিরে যাও
$ cd ..
$ pwd                             # এখন ~/code/lab-এ থাকার কথা

# absolute path দিয়ে সরাসরি notes-এ
$ cd ~/code/lab/documents/notes
$ pwd
output — ধাপে ধাপে
/root/code/lab/projects
/root/code/lab
/root/code/lab/documents/notes
দুই রকম path

Absolute path শুরু হয় / দিয়ে — যেমন /root/code/lab। তুমি যেখানেই থাকো, এই path সবসময় একই জায়গা বোঝায়।

Relative path শুরু হয় তোমার বর্তমান অবস্থান থেকে — যেমন projects বা ..। . মানে "এখানেই", .. মানে "এক ধাপ উপরে"।

খালি cd লিখে Enter দিলে সরাসরি home-এ ফিরে যাবে। আর cd - দিলে ঠিক আগে যেখানে ছিলে সেখানে ফিরবে।

ls — ভেতরে কী আছে?

লক্ষ্য: directory-র ভেতরের জিনিস দেখা, hidden file সহ।

bash
# সাধারণ তালিকা
$ ls

# বিস্তারিত + hidden file সহ
$ ls -la

# অন্য directory-তে না গিয়েই সেটার ভেতর দেখা
$ ls ~/code/lab/projects
output — ls -la (notes directory-তে)
total 16
drwxr-xr-x 2 root root 4096 Sep  6 11:20 .
drwxr-xr-x 4 root root 4096 Sep  6 11:20 ..
-rw-r--r-- 1 root root   14 Sep  6 11:20 meeting.txt
-rw-r--r-- 1 root root   10 Sep  6 11:20 todo.txt
প্রথম দুটো লাইন . আর .. — নিজে আর তার parent। এগুলো সবসময় থাকে।

ব্যাখ্যা: -l মানে long format — permission, owner, size, তারিখ সব দেখায়। -a মানে all — . দিয়ে শুরু হওয়া hidden file গুলোও দেখায়। দুটো একসাথে -la।

যা দেখছোমানে
d দিয়ে শুরুএটা একটা directory
- দিয়ে শুরুএটা একটা সাধারণ file
rw-r--r--কে পড়তে/লিখতে/চালাতে পারবে — permission
root rootfile-এর owner আর group
সাথে সিমুলেটর

Permission-এর rwxr-xr-x অংশটা এখনই পুরো বুঝতে হবে না। কৌতূহল হলে Permission Calculator সিমুলেটর খুলে switch গুলো নেড়ে দেখতে পারো।

find — নাম ধরে file খোঁজা

লক্ষ্য: directory-র গভীরে লুকিয়ে থাকা file খুঁজে বের করা।

bash
$ cd ~/code/lab

# সব .txt file খুঁজে বের করো
$ find . -name "*.txt"

# notes directory-র ভেতরের শুধু file গুলো
$ find ./documents/notes -type f
output
$ find . -name "*.txt"
./documents/reports/plan.txt
./documents/notes/meeting.txt
./documents/notes/todo.txt

$ find ./documents/notes -type f
./documents/notes/meeting.txt
./documents/notes/todo.txt

ব্যাখ্যা: find-এর গঠনটা হলো — find <কোথায় খুঁজব> <কী শর্তে>। এখানে . মানে "এখান থেকে শুরু করে নিচের সব", -name দিয়ে নামের প্যাটার্ন, আর -type f দিয়ে শুধু file (directory বাদ)।

শর্তকী করে
-name "*.txt"নাম .txt দিয়ে শেষ হয় এমন সব
-type fশুধু file
-type dশুধু directory
-iname "*.TXT"নামের ছোট-বড় হাতের অক্ষর ধরবে না
Quote দিতে ভুলো না

find . -name *.txt — quote ছাড়া লিখলে shell নিজেই *.txt টা আগে বদলে ফেলে, তখন find ভুল জিনিস পায়। তাই সবসময় "*.txt" quote-এর ভেতরে লেখো।

grep — file-এর ভেতরের লেখা খোঁজা

লক্ষ্য: কোন file-এ কোন কথাটা লেখা আছে সেটা বের করা।

bash
# documents-এর ভেতরের সব file-এ "Meeting" খোঁজো
$ grep -r "Meeting" ~/code/lab/documents

# শুধু .txt file গুলোর ভেতরে "Plan" খোঁজো
$ grep "Plan" ~/code/lab/documents/*/*.txt
output
$ grep -r "Meeting" ~/code/lab/documents
/root/code/lab/documents/notes/meeting.txt:Meeting Notes

$ grep "Plan" ~/code/lab/documents/*/*.txt
/root/code/lab/documents/reports/plan.txt:Project Plan
Output-এর গঠন: file-এর path : যে লাইনে পাওয়া গেছে

ব্যাখ্যা: grep মানে Global Regular Expression Print। find খোঁজে নাম ধরে, আর grep খোঁজে ভেতরের লেখা ধরে — এই পার্থক্যটা মনে রাখা জরুরি।

Flagকী করে
-rdirectory-র ভেতরে ঢুকে ঢুকে খোঁজে
-iছোট-বড় হাতের অক্ষর ধরে না
-nকত নম্বর লাইনে পাওয়া গেছে দেখায়
-lশুধু file-এর নাম দেখায়, লাইন না

নিজে করো — Search Challenge

নিচের তিনটে কাজ নিজে চেষ্টা করো। উত্তর দেখার আগে নিজে লিখে চালিয়ে দেখো:

  1. যেসব file-এর ভেতরে "List" কথাটা আছে, সেগুলো খুঁজে বের করো।
  2. lab directory আর তার ভেতরের সব জায়গা থেকে .txt file গুলো বের করো।
  3. lab-এর ভেতরের শুধু directory গুলোর তালিকা করো (file বাদ দিয়ে)।
সমাধান দেখো
bash — solution
# ১ — ভেতরের লেখা ধরে খোঁজা
$ grep -r "List" ~/code/lab

# ২ — নাম ধরে খোঁজা
$ find ~/code/lab -name "*.txt"

# ৩ — শুধু directory
$ find ~/code/lab -type d
output
১ → /root/code/lab/documents/notes/todo.txt:Todo List

২ → /root/code/lab/documents/reports/plan.txt
       /root/code/lab/documents/notes/meeting.txt
       /root/code/lab/documents/notes/todo.txt

৩ → /root/code/lab
       /root/code/lab/projects
       /root/code/lab/projects/website
       /root/code/lab/documents
       /root/code/lab/documents/reports
       /root/code/lab/documents/notes

খেয়াল করো — ৩ নম্বরের output-এ ~/code/lab নিজেও আছে। কারণ যেখান থেকে খোঁজা শুরু, সেটাও একটা directory।
