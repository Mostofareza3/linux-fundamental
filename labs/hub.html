Linux Labs

বই পড়ে concept বোঝা হয়, আর lab করে হাত তৈরি হয়। এখানে প্রতিটা lab-এ একটা করে সম্পূর্ণ কাজ আছে — environment বানানো থেকে শুরু করে verify করা পর্যন্ত। প্রতিটা command নিজের terminal-এ চালাও, output মিলিয়ে দেখো, তারপর পরের ধাপে যাও।

কীভাবে lab করবে

Lab পড়ার জিনিস না — করার জিনিস। একটা terminal খুলে পাশে রাখো, আর প্রতিটা command copy করে নয়, নিজে টাইপ করে চালাও। টাইপ করলে ভুল হয়, ভুল হলে error আসে, আর error পড়তে শেখাটাই আসল Linux শেখা।

প্রতিটা ধাপের পরে expected output দেওয়া আছে। তোমার output হুবহু না মিললেও চিন্তা নেই — UID/GID সংখ্যা বা তারিখ আলাদা হবেই। গঠনটা মিললেই হলো।

— শেষ
চেকলিস্ট কাজ করে

প্রতিটা lab-এর শেষে একটা checklist আছে। ঘরগুলোতে টিক দিলে সেটা তোমার browser-এ save থাকবে — পরে ফিরে এলে কোন lab কতদূর করেছিলে সেটা এই পাতাতেই দেখতে পাবে।

শুরুর আগে যা লাগবে

  • একটা Linux terminal — Ubuntu, WSL, অথবা যেকোনো VPS। macOS-এও বেশিরভাগ চলবে, তবে user/group সংক্রান্ত কিছু command শুধু Linux-এ চলে।
  • sudo চালানোর permission — কিছু lab-এ দরকার হবে।
  • Terminal-এ basic চলাফেরার অভ্যাস — Tab দিয়ে auto-complete, ↑ দিয়ে আগের command।
Keyboard

← → দিয়ে lab বদলাবে। প্রতিটা code block-এর copy বোতামে চাপলে prompt চিহ্ন ($) বাদ দিয়ে শুধু command টা copy হবে।
